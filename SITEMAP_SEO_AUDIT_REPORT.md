## 🔍 TROUBLESHOOTING

### Issue: Sitemap returns 404

**Solution:**
```powershell
# Rebuild Next.js
cd frontend
npm run build
```

Ensure `sitemap.ts` exists in `src/app/` directory.

### Issue: URLs use wrong domain

**Solution:**  
Set `NEXT_PUBLIC_SITE_URL` in production environment:
```env
NEXT_PUBLIC_SITE_URL=https://tzwellnesscentre.com
```

### Issue: Dynamic content not appearing

**Solution:**  
Check Supabase connection:
1. Verify `NEXT_PUBLIC_SUPABASE_URL` is set
2. Verify `NEXT_PUBLIC_SUPABASE_ANON_KEY` is set
3. Check database tables have published content:
   - `services` table: `is_active = true`
   - `blog_posts` table: `is_published = true`
   - `events` table: `is_active = true`

### Issue: Sitemap not updating

**Solution:**  
Next.js caches sitemap responses. Force regeneration:
```powershell
# Redeploy
vercel --prod --force
```

Or wait for automatic revalidation (typically 24 hours).
